# Proyecto Unidad 4 — Tablero de Tareas y Formulario de Colaborador

## Descripción

Este proyecto corresponde a la Unidad 4 de programación web y está dividido en dos partes.

La **Parte 1** consiste en un tablero de tareas para gestionar actividades de un equipo, permitiendo trabajar con estados, prioridades, filtros y estadísticas.

La **Parte 2** consiste en un formulario de registro de colaboradores que utiliza HTML, CSS y JavaScript para realizar validaciones nativas y manuales mediante la Constraint Validation API.

---

# Parte 1 — Tablero de Tareas

## Funcionalidades

El tablero permite:

- Agregar tareas.
- Definir título y descripción.
- Seleccionar prioridad.
- Manejar diferentes estados:
  - Pendiente.
  - En progreso.
  - Completada.
- Filtrar tareas por estado.
- Filtrar tareas por prioridad.
- Mostrar estadísticas del tablero.
- Generar identificadores únicos para las tareas.

## Tecnologías

- HTML5
- CSS3
- JavaScript ES6+
